# json-tools

CLI for quick experiments and daily scripting. Work in progress.


## Features

- no build step needed
- single-file friendly
- works on Linux/macOS
- easy to extend

```
.

├── src/

├── .gitignore

```

## Usage

```bash
npx ts-node src/index.ts
```
